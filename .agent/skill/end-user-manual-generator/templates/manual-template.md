# How to Use This Manual

This manual is organized around tasks users need to complete. Find your role or task in the Quick Task Finder, review the workflow overview, and follow the numbered steps. Screenshot markers use the same numbers as the related instructions.

## Symbols and callouts

- **IMPORTANT** — requirement that affects completion or data integrity.
- **WARNING** — action that may cause loss, disclosure, or an irreversible change.
- **NOTE** — additional explanation.
- **TIP** — optional shortcut.
- **EXPECTED RESULT** — what should be visible when the task is complete.
