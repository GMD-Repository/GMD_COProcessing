## Create a New Request

**Purpose:** Create a new request record.  
**Applicable role:** Authorized requester.  
**Before you begin:** Sign in using an account with permission to create requests.  
**Required inputs:** The information required by the actual request form.

### Procedure

1. Open the **Requests** module from the main navigation. The Requests page appears.
2. Select **New Request**. The new-request form opens.
3. Enter the required information in the fields shown on the form. Use the format indicated beside each field.
4. Review the information for accuracy.
5. Select **Submit**. Wait for the system response before leaving the page.
